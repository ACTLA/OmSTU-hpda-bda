# АБД · Лабораторная работа №1

**Тема:** развёртывание и конфигурирование среды хранения данных.
**Источник:** `music_tracks`. Правила очистки берутся из ВОиАД ([docs/hpda/lab01](../../hpda/lab01/README.md)).

## Что реализовано

| Требование задания | Где |
|---|---|

## Архитектура

`CSV → src.music_tracks → stg.music_tracks → ods.music_tracks → dwh (факт + измерения)`

Каждый шаг можно запускать повторно: STAGING перезаливается целиком, ODS и факты за период
удаляются и загружаются заново, поэтому дублей не возникает.

Результат загрузки: `src` — 65 079 строк, `stg` — 65 079, `ods` — 61 253.

## Поле `dt`

В источнике нет даты. `dt` генерируется детерминированно: неделя (из 26, начиная с 06.01.2025) выбирается
по хэшу содержимого строки, день недели берётся из колонки `Day`. Поэтому `dt` согласована с `Day`,
а полные дубликаты получают одинаковую `dt`.

## DWH (снежинка)

Факт `fact_listening` — одно прослушивание. Измерения: `dim_user`, `dim_genre`, `dim_city`,
`dim_track → dim_artist`, `dim_date → dim_month`, `dim_time → dim_daypart`.
Жанр и город хранятся в факте, так как для части треков и пользователей они различаются.
