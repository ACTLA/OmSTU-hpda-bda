# ВОиАД · Лабораторная работа №1

**Тема:** формирование и подготовка данных для аналитической обработки.
**Источник:** `music_tracks` — лог прослушиваний (65 079 записей; `userID, Track, artist, genre, City, time, Day`).

## Что реализовано

| Требование задания | Где |
|---|---|
| Единое Streamlit-приложение | `music_app/app/main.py` |
| Страница «Исследовательский анализ данных» | `music_app/app/views/eda.py`, расчёты — `music_app/modules/analysis.py` |
| Общие показатели, таблицы, графики, интерактивные элементы | разделы 1–6 страницы (фильтры в боковой панели) |
| Выявленные проблемы качества и итоговые выводы | разделы 7 и 9 страницы |
| Алгоритм очистки: признак, условие, способ, обоснование | раздел 8 страницы |
| Алгоритм в виде SQL-процедуры | `music_app/sql/03_load_ods.sql` (`ods.load_ods`), код показан в разделе 8 |
| Сводка результатов анализа | `music_app/reports/eda_summary.json` (кнопка в разделе 10) |

## Алгоритм очистки

| Проблема | Найдено | Обработка |
|---|---|---|
| Служебная колонка индекса | 1 колонка | не переносится |
| Лишние пробелы в `Track` / `artist` | 32 / 36 | обрезка |
| `userID` короче 8 символов | 4 078 (6,27%) | дополнение нулями слева до 8 |
| Пропуски `Track` / `artist` / `genre` | 1 231 / 7 203 / 1 198 | заменяются на `'unknown'` |
| Некорректные `userID`, `City`, `Day`, `time` | 0 | запись исключается |
| Полные дубликаты | 3 826 (5,88%) | остаётся одна запись |
| Потенциальные дубликаты, треки с несколькими жанрами, пользователи из разных городов | 684 / 91 / 33 | без изменений |

Обоснования и условия выявления — в разделе 8 страницы. Алгоритм применяется при загрузке STAGING → ODS
в лабораторной по АБД ([docs/bda/lab01](../../bda/lab01/README.md)).
